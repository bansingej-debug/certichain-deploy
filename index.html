Questions

Is the blockchain real?

Yes. Every certificate is written into a block with a SHA-256 hash, a link to the previous block and a mined proof of work. The chain lives in this site's shared database, so it works like a private or consortium ledger. It is not a public network such as Ethereum, and the admin dashboard can re-validate every block at any time.

Are the privacy proofs true zk-SNARKs?

No. They are salted Merkle proofs, a standard selective-disclosure technique. The verifier learns only the fields you tick and checks them against the on-chain root. Range statements such as "grade above 60%" work because the issuer commits that fact as its own field when the certificate is issued.

Is my file uploaded anywhere?

It is hashed in your browser. If an image does not match an issued original, you can allow Claude to examine it for signs of forgery, and only then is the image sent for analysis.

Can a screenshot or photo of a certificate be verified?

Yes, if you also have its verification code, which is in the certificate's QR code. The AI reads the name, course, grade, year and institution printed on the copy and compares them with the record the institution registered, so an edited grade or name is caught. Without the code, the copy is still examined for signs of editing, and you still get a clear Original or Fake.

Who can issue certificates?

Only the owner and editors of this site. Everyone else can verify, keep a wallet and rate results.

What if a real certificate is flagged?

The report shows which signal failed. Low-quality scans can lower the pixel and AI scores, so an admin can review the case.
